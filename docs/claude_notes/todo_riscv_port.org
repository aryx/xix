* Phase 0 -- harness
** DONE diff harness script (assemble+link both sides, cmp -l, qemu-riscv32)
   scripts/diff-riscv.sh + test-riscv.sh, mirrors the ARM/MIPS ones.
   goken's il needs `-c` (disable RVC instruction compression --
   see below) `-s` (strip native symbol table, same as ARM/MIPS).
   No -H flag needed on either side (il defaults to ELF already,
   like vl; oil's CLI.ml always defaults to "elf" regardless of arch).
** DONE discover goken's il compresses instructions (RVC) by default
   linkers/il/compress.c, called unconditionally from asm.c's encode
   loop unless `-c` is passed (`if(!debug['c'] && o->ctype)`) --
   found by disassembling goken's default output and hitting 16-bit
   opcodes a plain-RV32 disassembler couldn't decode (e.g. bytes
   `05 45` = `C.LI a2,13`, replacing a 4-byte `addi a2,zero,13`).
   Decided NOT to implement compression in xix (substantial separate
   feature: deciding what's losslessly shrinkable, then re-doing
   layout since it changes instruction sizes/addresses). The harness
   always passes goken's `-c` so the comparison is apples to apples.

* Notes for later
** MOVB/MOVH/MOVBU/MOVHU not wired in the assembler
   See notes_riscv_port_plan.txt's "Not yet wired in the assembler"
   section -- Move1 vs Move2's exact intended split for byte/half
   isn't obvious from the AST alone; investigate goken's il/asm.c
   case 10 ("sign extend") and the a.y grammar before guessing.
** Rewritev.ml (MIPS) may have a latent leaf-with-locals gap
   Found while reading goken's il/noop.c for RISC-V's 3-way leaf/
   frame logic: MIPS's Rewritev.ml only has a 2-way split (leaf-with-
   no-locals vs everything else), always doing the full RLINK save/
   restore even for a leaf procedure that merely has locals. Whether
   goken's vl/noop.c actually has the same 3-way distinction (making
   this a real MIPS gap) wasn't checked -- no MIPS fixture currently
   exercises a leaf-with-nonzero-declared-size TEXT to expose it
   either way.
